# Iteration 1 Plan and Retrospective

## Plan
* **Goal:** Deliver the walking skeleton of FoodFlow, including a console UI for browsing restaurants, managing a cart, and placing a cash order.
* **Scope:** Implement core domain models (`Customer`, `Cart`, `Order`, `Restaurant`), JSON data loading from `data/restaurants.json`, and a console-based UI.

## Retrospective
* **Keep:** Dividing the work early between code implementation and documentation.
* **Problem:** Setting up the Git/GitHub branch workflow and PlantUML environment took more time than expected initially.
* **Try:** Create smaller pull requests and assign reviewers earlier in the iteration to speed up the merging process.
